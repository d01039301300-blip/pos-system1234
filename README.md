# SYSTEM — نظام إدارة الأعمال 1.0.1

## التثبيت والتجربة

شغّل المثبّت المناسب لمعمارية Windows، ثم افتح البرنامج من الاختصار. لا تُشغّل أكثر من مثبّت على نفس النسخة. تبدأ التجربة من أول تشغيل ومدتها 30 يوماً، وتُحفظ بيانات البرنامج في:

`%APPDATA%\GeneralBusinessPOS`

الحسابات الافتراضية:

- `admin / admin123`
- `inventory / inv123`
- `cashier / cash123`

## عند ظهور Smart App Control أو SmartScreen

المشروع الحالي يضبط `signExecutable: false`، لذلك قد يمنع Windows المثبّت غير الموقّع برسالة تعذر التحقق من الناشر. لم يُنفّذ أي تجاوز للحماية ولم تُطلب إزالتها. الحل الإنتاجي هو توقيع المثبّت بشهادة توقيع تجارية OV أو EV، أو خدمة توقيع Microsoft. لا تُخزّن الشهادة أو كلمة مرورها داخل المشروع.

## البيانات والتشغيل الأول

عند أول تشغيل يُنشأ `config.json` وتُختار قاعدة البيانات، والافتراضي `database.json` داخل مجلد بيانات المستخدم. عند تعذر الوصول إلى مسار محفوظ، يعرض البرنامج المسار المفقود قبل اقتراح قاعدة محلية جديدة.

## محتويات المصدر

المصدر يحتوي ملفات التطبيق والخادم وملفات Electron والأصول. مجلد `node_modules` ومخرجات البناء ليست جزءاً من حزمة المصدر النهائية.

## حدود الاختبار

اختُبرت مسارات التشغيل الأولى والتجربة وحارس التنقل دون تشغيل Electron أو أي مثبّت على جهاز المستخدم. الإرسال الحقيقي عبر SMS أو WhatsApp لم يُختبر.
